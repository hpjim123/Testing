# Window Art Works

Window painting website concept with a seasonal design catalog, custom greetings, photo upload, adjustable artwork overlays, and downloadable PNG mockups.

## Preview
Open index.html in a browser. This is an interactive concept preview using stock storefront photos and original illustrative vector designs, not completed customer work. The artwork preview is a flat composite, not a photorealistic AI render.

## Source
The full framework source is in window-art-works-source.zip.

## Local quote submissions
Run `node window-art-works-local.mjs` with Node 22+, then visit http://127.0.0.1:5173. The local server stores submitted quote details and photos in a private local quote-requests folder. Email delivery is not configured.

GitHub Pages serves only the static preview. Quote submission requires a backend and is not supported by GitHub Pages.

Stock photography credits and links are included in the website footer.
